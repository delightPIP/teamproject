# `/toIssue` — GitHub 이슈(Issue) 자동 등록 스킬

`docs/SPEC.md`와 `docs/POLICY.md`를 분석하여, 팀원들이 겹치지 않고 병렬로 작업할 수 있도록 **GitHub 레포지토리에 이슈(Issues)들을 즉시 등록**합니다.  
(※ 이미 GitHub Issues에 등록되므로 `docs/ISSUES.md` 같은 불필요한 로컬 문서는 생성하지 않습니다.)

## 실행 절차

### 1. `docs/SPEC.md` 기반 작업 분해
- 스펙 문서를 읽고, 병렬로 작업할 수 있는 3~5개의 독립 기능 단위로 작업을 나눕니다.
- 각 이슈마다 **제목, 담당 파일/모듈, 완료 조건(Checklist)**을 명확히 정의합니다.

### 2. GitHub 이슈 자동 생성 (`gh issue create`)
- AI 에이전트는 GitHub CLI(`gh`)를 사용하여 현재 원격 레포에 이슈를 직접 생성합니다.

```bash
gh issue create \
  --title "[모듈명] 작업 제목" \
  --body "### 작업 내용
- 세부 작업 설명

### 담당 파일
- \`src/파일명.py\`

### 완료 조건
- [ ] 체크리스트 1
- [ ] 체크리스트 2"
```

> **GitHub CLI(`gh`)가 설치되지 않았거나 로그인이 안 된 환경인 경우:**
> - 팀원이 GitHub 웹에서 바로 복사하여 등록할 수 있도록 이슈 제목과 본문 내용을 깔끔하게 출력합니다.
> - 또는 일괄 등록 가능한 원클릭 bash/powershell 명령어를 제공합니다.

### 3. 생성 결과 요약 보고
- 등록된 GitHub 이슈 번호와 제목, 담당 영역을 요약하여 팀원들이 바로 나눠 가질 수 있도록 안내합니다:
  - `#1 [뼈대] 기본 레이아웃 및 진입점 구성`
  - `#2 [데이터] 데이터 로드 및 전처리`
  - `#3 [분석/차트] 카테고리별 비교 시각화`
  - `#4 [홈/통합] 메인 화면 조립 및 배포`
