# 🎬 데모 시나리오와 인수 기준 (DEMO)

> **상태**: 1차 초안 · 2026-11-11 · 담당 PO · 기준 문서 [docs/PRD.md](PRD.md) 2·3·4장, [docs/SPEC.md](SPEC.md), [docs/POLICY.md](POLICY.md)
> 인수 기준은 GitHub 이슈 #1~#10의 완료 조건을 **사용자 눈에 보이는 결과**로 다시 쓴 것이다. 이슈의 체크리스트가 "만들었다"면, 여기는 "이렇게 동작한다"다.

## 1. 데모 시나리오 (PRD 4장 유저 저니, 8분)

데모는 PRD 4장의 저니를 그대로 따라간다. 발표자는 PO, 화면 조작도 PO가 한다. 개발자는 질문을 받는다.

### 사전 준비

| 준비 | 내용 | 담당 |
| --- | --- | --- |
| 데모 PC | 윈도우 노트북 1대, 맥 1대 (한쪽을 주 화면, 다른 쪽은 드롭 동작만 보여 줌) | PO |
| 보관함 시드 | **7일 전 날짜**로 넣은 별 3개 이상 (재발견이 뜨려면 필수, POLICY 2-2), 이번 주 별 20개, 행성 4개. 시드 스크립트는 `createdAtUtc`를 직접 지정한다 | 개발 B |
| 알림 시각 | SPEC 2-4의 `notificationTime`은 15:00 고정(잠정)이라 데모 시각에 맞출 수 없다. **(SPEC 제안)** 개발 전용 환경 변수로 알림 시각을 바꿀 수 있게 한다. 배포 빌드에는 넣지 않는다 | PO (SPEC 1-2·2-4에 반영) |
| 드롭할 자료 | 캡처 이미지 1장, PDF 1개, 링크 1개(제목이 잘 뽑히는 사이트), 텍스트 한 줄 | PO |
| 브라우저 | 기본 브라우저에 다른 탭 없이, WebGL 되는지 전날 확인 | 개발 C |

### 진행

| 분 | 보여 주는 것 | 말하는 것 | 성공 기준 |
| --- | --- | --- | --- |
| 0~1 | 드롭존이 화면 가장자리에 접혀 있다. 트레이 아이콘을 보여 준다 | "PC를 켜면 이렇게 떠 있습니다. 앱은 모으기만 합니다" | — |
| 1~3 | 캡처·PDF·링크·텍스트를 하나씩 드롭한다. 확인 카드에서 행성을 하나 바꾸고 메모를 붙인다 | "놓은 순간부터 3초 안에 저장됩니다. 정리는 여기서 끝, 나머지는 웹에서" | 모으기 3초 |
| 3~4 | `Ctrl+Shift+Space`로 클립보드 텍스트를 넣는다 | "복사만 해 두고 단축키 한 번" | — |
| 4~5 | 재발견 알림이 뜬다. 클릭한다 → 브라우저가 열리며 그 별이 있는 행성으로 이동한다. **알림 클릭이 안 되면** 우주 홈의 재발견 카드 [보러 가기]로 같은 흐름을 보여 준다 | "일주일 전 오늘의 별입니다. 이게 핵심입니다" | 알림 클릭 → 별 상세 (대안: 카드) |
| 5~6 | ⌂ 조망으로 돌아간다. 오늘 → 이번 주로 기간을 바꾼다 | "조작 없이 오늘 우주 전체가 보입니다" | 한눈에 보인다 (조작 0회) |
| 6~7 | 행성 목록에서 하나를 눌러 바로 간다. 패널에서 별을 열고, 다른 행성으로 옮긴다. 잠깐 둘러본다 (3D안이면 WASD 비행, 2.5D안이면 드래그·휠 확대) | "둘러보기는 재미, 목록은 길. 클릭 2번이면 어디든" | 클릭만으로 찾는다 (2회 이내) |
| 7~8 | 별 2개와 행성 1개를 탐사선에 싣고 미리보기 → 복사 → Claude에 붙여넣는다 | "내가 고른 것만, 미리 보고, 복사" | 내보내기 1분 |

### 축소했을 때의 데모

PRD 3장의 축소 순서(MCP 리소스 형식 → (3D안일 때) 착륙 연출 → 행성 합치기)를 적용해도 위 8분은 그대로 간다. MCP 리소스 라디오가 없고, 바로 가기가 연출 없이 이동하고, 합치기 메뉴가 없을 뿐이다. **모으기와 재발견(1~5분)은 줄이지 않는다.**

## 4. 데모 전날 체크리스트

- [ ] 시드 데이터 들어감 (7일 전 별 3개 이상 확인)
- [ ] 2장 인수 기준 중 데모 경로에 있는 것(AC-수집-1·2·3·6·7, AC-재발견-1·2·3, AC-우주-1·3·4·5, AC-정리-1·6, AC-탐사선-1·2·4) 전부 통과
- [ ] 성공 기준 "확정" 4개(모으기 3초, 조작 0회, 클릭 2회, 내보내기 1분) 측정값 기록됨
- [ ] 데모 PC에서 리허설 2회, 두 번째는 시간 재기 (8분 ± 1분)
- [ ] 축소된 기능이 있으면 발표 멘트에서 뺌
- [ ] 패키징된 앱이 데모 PC의 보안 정책(윈도우 앱 제어·맥 Gatekeeper)에 막히지 않는지 **전날** 실행해 봄 (스파이크에서 서명 없는 exe가 윈도우 앱 제어 정책에 막혔다 → 코드 서명 또는 설치 안내 필요)
- [ ] 설치본에서 알림 클릭 → 웹 열기가 되는지 **전날** 확인. 안 되면 데모 4~5분은 재발견 카드 경로로 바꿈
