# 🎤 리허설 진행표 (REHEARSAL)

> **상태**: 2026-11-11 · 담당 PO · [DEMO.md](DEMO.md) 1장을 발표자가 보면서 읽을 수 있게 옮긴 것
> 이 문서는 **무대에서 손에 들고 보는 종이**다. 기준과 근거는 DEMO.md에 있고, 여기에는 **할 것과 할 말, 막혔을 때의 대안**만 둔다.

## 0. 시작 전 (5분)

```bash
node scripts/demo-reset.mjs
```

이 한 줄이 하는 일: 데모 보관함(`문서/SpaceLog-demo`)을 비우고 다시 시드한다(7일 전 별 3개 + 이번 주 20개, 행성 4곳), 수집 앱 설정이 그 보관함을 보게 하고, **오늘 알림을 다시 받을 수 있게 되돌린다**. 평소 보관함(`문서/SpaceLog`)은 건드리지 않는다.

그다음 스크립트가 알려 주는 명령으로 앱을 띄운다 (알림 시각이 약 3분 뒤로 잡힌다):

```bash
cd apps/collector && SPACELOG_NOTIFY_AT=HH:MM npm start
```

| 확인 | 왜 |
| --- | --- |
| [ ] `web/dist`가 있다 (없으면 `npm install && npm run build -w @spacelog/web`) | 없으면 "우주 보기"가 빈 화면 |
| [ ] 드롭할 자료 4개를 바탕화면에 모아 둔다: 캡처 이미지 · PDF · 링크(브라우저 탭) · 텍스트 한 줄 | 무대에서 파일 찾지 않기 |
| [ ] 브라우저에 다른 탭 없이, 한 번 열어 WebGL이 되는지 본다 | AC-우주-7 |
| [ ] 트레이 아이콘이 보이고 드롭존이 가장자리에 접혀 있다 | 0~1분 장면 |
| [ ] **알림이 실제로 뜨는지** 리허설에서 한 번 본다 | 가장 많이 깨지는 곳 |

> **리허설을 두 번 하려면 매번 `demo-reset.mjs`를 다시 돌린다.** 시드는 별이 있는 보관함에 넣지 않고, 재발견 알림은 하루 1번이라 그대로 두면 두 번째에는 안 뜬다.

## 1. 8분 진행표

| 분 | 할 것 | 할 말 | 막히면 |
| --- | --- | --- | --- |
| **0~1** | 접힌 드롭존과 트레이 아이콘을 보여 준다 | "PC를 켜면 이렇게 떠 있습니다. **이 앱은 모으기만 합니다.**" | — |
| **1~3** | 캡처 → PDF → 링크 → 텍스트를 하나씩 드롭. 확인 카드에서 행성을 하나 바꾸고 메모 한 줄 | "놓은 순간부터 **3초 안에** 저장됩니다. 정리는 여기서 끝, 나머지는 웹에서" | 행성·메모에서 오류가 뜨면 **아무것도 바꾸지 말고 [완료]**. 멘트: "행성은 자동으로 배정됩니다. 정리는 웹에서 합니다" |
| **3~4** | `Ctrl+Shift+Space`로 클립보드 텍스트 넣기 | "복사만 해 두고 단축키 한 번" | 단축키가 안 먹으면 트레이 메뉴의 [클립보드 넣기] |
| **4~5** | 알림이 뜬다 → 클릭 → 브라우저가 열리고 그 별의 상세 | "**일주일 전 오늘의 별입니다. 이게 핵심입니다.**" | ① 알림 클릭이 안 되면 → 트레이 **[오늘의 별 보기]** ② 그것도 안 되면 → 우주 홈의 재발견 카드 [보러 가기] |
| **5~6** | ⌂ 조망으로 돌아가 오늘 → 이번 주로 기간 전환 | "조작 없이 오늘 우주 전체가 보입니다" | 끊기면 기간을 **오늘**로 좁힌다 |
| **6~7** | 행성 목록에서 하나 클릭 → 패널에서 별 열기 → 잠깐 비행 | "둘러보기는 재미, 목록은 길. **클릭 2번이면 어디든**" | 비행이 어색하면 목록 클릭만으로 |
| **7~8** | 별 2개와 행성 1개를 탐사선에 싣고 미리보기 → 복사 → Claude에 붙여넣기 | "내가 고른 것만, 미리 보고, 복사" | 복사가 막히면 "선택했어요, Ctrl+C로" 안내대로 |

## 2. 말하지 않을 것 / 먼저 말할 것

| 상황 | 멘트 |
| --- | --- |
| 썸네일 자리에 아이콘이 보일 때 | "썸네일과 링크 제목은 **다음 단계**입니다" (이번 범위에서 뺌, PRD 3장) |
| 탐사선 MCP 리소스 탭 | 열지 않는다. 축소 1순위라 발표에서 뺀다 |
| 설치 파일을 묻는 질문 | "서명 전이라 오늘은 개발 모드로 띄웠습니다. 받는 곳 페이지에 설치 안내가 있습니다" |
| 측정값을 묻는 질문 | 재지 않은 것은 **"아직 측정하지 않았습니다"**. 맥·패키징 빌드·재발견 비율이 여기 해당한다 |

## 3. 측정 기록란 (리허설에서 채운다)

| 기준 | 목표 | 리허설 값 | 비고 |
| --- | --- | --- | --- |
| 모으기가 빠르다 | 3초 이내 (10회 중 9회) | | 드롭 10회. 값은 `%APPDATA%\SpaceLog\collector-metrics.jsonl`의 `dropToConfirmMs` |
| 한눈에 보인다 | 조작 0회 | | 웹 첫 화면에서 행성이 다 보이는가 |
| 클릭만으로 찾는다 | 클릭 2회 이내 | | 우주 홈 → 행성 패널 |
| 내보내기가 빠르다 | 1분 이내 | | 탐사선 열기 → 복사 완료, 3회 |
| 전체 시간 | 8분 ± 1분 | | 두 번째 리허설에서 잰다 |

**다시 만난다(핵심)** 는 데모가 당일이라 측정하지 않는다. 뜬 횟수와 연 횟수만 적고 비율로 쓰지 않는다 (PRD 9장).

## 4. 끝난 뒤

- 설정 창에서 보관함 위치를 평소 폴더(`문서/SpaceLog`)로 되돌린다.
- 리허설에서 깨진 것이 있으면 DEMO 2장 인수 기준의 해당 줄에 적는다. **고치지 못한 것은 발표 멘트에서 뺀다.**
