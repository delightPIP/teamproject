# 🎙️ 사용자 인터뷰 가이드 (INTERVIEW)

> **상태**: 1차 초안 · 2026-11-11 · 담당 PO · 기준 문서 [docs/PRD.md](PRD.md) 9장, [docs/RESEARCH.md](RESEARCH.md) 7장
> **상태: 보류 (2026-11-11).** 이번 일정에 인터뷰를 하지 못한다 (PRD 9장). 이 가이드는 그대로 두고, 하게 되면 이대로 진행한다. 아래 **판정 기준은 인터뷰 전에 정해 둔 것**이라 결과를 보고 바꾸지 않는다.

## 1. 무엇을 확인하나

PRD 9장의 다섯 가지 중 네 가지(V1·V2·V3·V5)를 인터뷰로 확인한다. PRD 9장 4번 "재발견이 실제로 다시 보게 하는가"는 인터뷰로 알 수 없으므로 데모 기간의 측정값으로 본다 ([docs/DEMO.md](DEMO.md) 3장). 대신 그 전제인 **알림 수용도(V4)**를 인터뷰에 추가했다. 각 항목은 "결과에 따라 무엇이 바뀌는지"가 정해져 있어야 인터뷰가 의사결정에 쓰인다.

| # | 확인할 것 | PRD 9장 | 근거 공백 | 바뀌는 문서 |
| --- | --- | --- | --- | --- |
| V1 | 타깃이 정말 20~30대인가 (Q4) | 1번 | C-01·C-02 | PRD 1장 타깃 문장 |
| V2 | PC에서 자료가 흩어지는 정도 | 2번 | RESEARCH 공백 2번 | PRD 3장 수집 앱 입력 방식 |
| V3 | AI에 자료를 넣는 불편이 실제로 있나 | 3번 | C-13, RESEARCH 공백 3번 | PRD 3장 4번 탐사선 축소 여부 |
| V4 | 하루 1번 재발견 알림을 받아들일까 | 없음 (추가) | — | POLICY 2-2 알림 시각·빈도 |
| V5 | 반례 사용자는 무엇이 다른가 | 5번 | — | PRD 1장 타깃 문장 (제외 조건) |

## 2. 누구를 만나나

| 구분 | 인원 | 조건 |
| --- | --- | --- |
| 핵심 타깃 후보 | 3~4명 | 20~30대, PC(맥 또는 윈도우)로 하루 4시간 이상 일하거나 공부함, 최근 1주일 안에 캡처·다운로드·링크 저장을 한 적 있음 |
| 연령 대조군 | 1~2명 | 40대 이상, 나머지 조건은 같음 (V1용) |
| 반례 | 1~2명 | 정리 욕구가 없다고 스스로 말하는 사람 1명, 노션·옵시디언 같은 정리 도구를 이미 매일 쓰는 사람 1명 (V5용) |

- 맥·윈도우 사용자를 섞는다. 한쪽만 모이면 수집 앱의 플랫폼 우선순위가 왜곡된다.
- 팀원과 팀원의 가족은 제외한다. 서비스를 이미 설명 들은 사람은 컨셉 반응이 왜곡된다.

**모집 질문 (스크리너, 1분)**

1. 나이대 (20대 / 30대 / 40대 이상)
2. 주로 쓰는 PC (맥 / 윈도우 / 둘 다)
3. 하루 PC 사용 시간 (4시간 미만이면 제외)
4. 최근 1주일 안에 한 것 (복수 선택): 화면 캡처 / 파일 다운로드 / 링크 저장 / 카톡 나와의 채팅 메모 / 메모앱 메모 / 없음
5. 자료 정리 도구를 매일 쓰나 (노션, 옵시디언, 에버노트 등) — 반례 분류용
6. 생성형 AI(ChatGPT, Claude 등)를 쓰나 (매주 / 가끔 / 안 씀)

## 3. 사전 과제 (인터뷰 전날, 5분)

RESEARCH 공백 2번을 채우기 위해 **개수만** 세어 온다. 파일 이름이나 내용은 받지 않는다.

| 항목 | 세는 방법 | 적는 값 |
| --- | --- | --- |
| 다운로드 폴더 전체 파일 수 | 윈도우: 탐색기에서 폴더 열고 `Ctrl+A` → 상태 표시줄 개수. 맥: Finder에서 폴더 열고 `⌘A` → 하단 개수 | 숫자 |

| 카톡 나와의 채팅에서 최근 30일 안에 보낸 메시지 수 | 대략 센다. 50개 넘으면 "50+" | 숫자 또는 50+ |

## 4. 진행 순서 (45분)

녹음은 동의를 받고 한다. 숫자와 인용은 PO의 PC에만 저장하고 서버에 올리지 않는다 (POLICY 1-1과 같은 원칙).

| 시간 | 단계 | 목적 |
| --- | --- | --- |
| 0~5분 | 소개·동의 | 녹음 동의, "정답이 없다", 서비스 이름과 설명은 **아직 하지 않는다** |
| 5~15분 | 지금 어떻게 모으나 | V1·V2. 사전 과제 숫자를 함께 본다 |
| 15~25분 | 다시 보나, 안 보면 왜 | V4의 전제. 문제정의 "다시 보게 하는 장치가 없다" 확인 |
| 25~33분 | AI에 자료를 넣어 봤나 | V3 |
| 33~42분 | 컨셉 보여 주기와 반응 | 화면정의서 와이어프레임 3장(드롭존, 우주 홈, 탐사선)을 보여 준다 |
| 42~45분 | 마무리 | 데모 참여 의향, 연락 허락 |

### 4-1. 지금 어떻게 모으나 (V1·V2)

1. 어제 PC로 뭘 하셨어요? 그 중에 "나중에 보려고" 남겨 둔 게 있었나요? 어디에 남겼어요?
2. (사전 과제 숫자를 보며) 다운로드 폴더에 파일이 N개네요. 이 중에 일부러 찾아서 다시 연 게 있나요? 마지막으로 그런 게 언제였어요?
3. 캡처는 왜 찍으세요? 찍은 캡처를 다시 찾은 적이 있어요? 어떻게 찾았어요?
4. (스크리너에서 나와의 채팅을 골랐으면) 카톡 나와의 채팅에는 뭘 보내세요? 거기 보낸 걸 다시 올려 본 적은요?
5. 지금 방식에서 제일 불편한 순간이 언제예요? (유도하지 않는다. "흩어져서"라는 말이 먼저 나오는지 본다)

### 4-2. 다시 보나 (V4)

6. 저장해 둔 걸 다시 보게 되는 계기가 있나요? (알림, 누가 물어봄, 우연히 발견, 없음)
7. 일주일 전에 저장한 걸 오늘 오후에 알림으로 한 개 보여 준다면 어떠세요? (답을 듣고 나서) 그런 알림이 하루에 몇 번이면 많다고 느낄 것 같아요?
8. 알림이 온다면 몇 시가 좋아요? (POLICY 2-2 잠정 15:00의 근거)

### 4-3. AI에 자료를 넣어 봤나 (V3)

9. ChatGPT나 Claude 같은 AI에 내 파일이나 캡처, 링크를 넣어 본 적 있어요? (없으면 10~11 건너뛰고 12로)
10. **AI에 자료를 넣으려고 마지막으로 파일을 찾고 복사한 게 언제였나요? 몇 분 걸렸나요?** (PRD 9장 질문 그대로)
11. 그때 넣은 게 몇 개였어요? 한 번에 넣었어요, 하나씩 넣었어요?
12. 내 자료를 AI에 넣는 게 꺼려진 적 있어요? 뭐가 걱정됐어요? (C-09 개인정보 우려 확인)

### 4-4. 컨셉 반응

와이어프레임을 보여 주고 "오늘 모은 자료가 저녁에 이렇게 보인다"고만 설명한다. 질문 13 전에는 우주·행성 같은 비유를 설명하지 않고 **먼저 무엇으로 보이는지 묻는다**. 13을 듣고 나서 화면 용어(별 = 자료 1개, 행성 = 묶음, 탐사선 = AI용 내보내기)를 한 줄로 설명한 뒤 14~18을 묻는다.

13. 이 화면이 뭘 하는 화면 같아요? (이해도)
14. 드롭존이 화면 가장자리에 늘 떠 있으면 어떨 것 같아요?
15. 넣은 직후 행성을 바꾸거나 메모를 붙이는 10초가 있는데, 할 것 같아요, 건너뛸 것 같아요?
16. (탐사선 화면) 고른 자료를 AI에 붙여넣을 수 있는 텍스트로 만들어 줘요. 이걸 쓰는 상황이 떠오르나요? 떠오르면 어떤 상황이에요?
17. (3D안·2.5D안 시안이 있으면 둘 다 보여 주고) 날아다니며 둘러보는 쪽과 확대·이동으로 둘러보는 쪽 중 어느 게 끌려요? 왜요? 둘러보는 것과 목록에서 바로 가는 것 중 뭘 더 쓸 것 같아요? (Q7 결정의 참고 자료)
18. 이 중에서 하나만 남긴다면 뭘 남기겠어요? (모으기 / 다시 알려 주기 / 한눈에 보기 / AI로 내보내기 / 아무것도 안 쓸 것 같다)

- 컨셉 반응(질문 13~17)은 판정 기준이 아니라 디자이너(전현우·신선이)와 개발 C에게 전달하는 참고 자료다. 질문 18만 V5 판정에 쓴다. 질문 17은 PO가 Q7(3D안 / 2.5D안)을 정할 때 참고하되, 시안 비교와 개발 C의 구현 의견이 우선이다 (PRD 6장 디자인 진행).

## 7. 참고: 국내 전국 조사와 맞춰 보기

한국리서치 2025년 3월 조사(전국 18세 이상 1,000명, [docs/RESEARCH.md](RESEARCH.md) 4장)는 "삶의 기록" 전반을 물은 것이라 PC 자료 수집과 같지 않다. 인터뷰 결과가 아래와 크게 다르면 모집이 치우친 것이므로 참가자 구성을 다시 본다.

- 18~29세와 30~39세는 **SNS(45%·46%)**와 **블로그(23%·20%)** 비중이 다른 연령보다 뚜렷이 높고, **디지털 메모 앱(23%·28%)**은 전체(21%)보다 조금 높으며, 종이 기반 도구(25%·17%)는 낮다. 업무·학습 관리 도구(노션 등)는 8%·9%로 전체(7%)와 비슷하다.
- 기록을 안 하거나 그만둔 이유에서 "기록한 내용을 다시 보지 않아 의미가 없다"는 1순위로 6%뿐이다 (기록하지 않는 120명 기준). 즉 "다시 안 본다"는 사용자가 **스스로 말하는** 불편이 아니다. 질문 5·6에서 "다시 안 보죠?"라고 유도하지 않는 이유다.
- 연령별 표본은 124~155명이라 위 수치는 참고용이다 (RESEARCH 4장 한계 열).
- AI 자동 기록 이용 의향은 18~29세 62%, 30~39세 55%로 전체(63%)보다 낮고, "AI 서비스는 개인정보 보호에 한계가 있을 것"에는 18~29세 73%, 30~39세 74%가 동의한다 (전체 65%). 질문 12를 반드시 묻는 이유다.
