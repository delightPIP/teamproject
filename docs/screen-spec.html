구현 기준 (SQ2, PO 확정 대기)

이미지·파일은 파일 이름과 종류(MIME)와 메모만 담는다. 원본 경로는 넣지 않는다(POLICY 2-8: 경로에 사용자 이름이 들어간다). .txt·.md는 본문을 20,000자까지 넣는다. 미리보기 예시는 SPEC 3-8의 Claude 프롬프트 형식이다.

공통 규칙

항목규칙
용어화면에서는 "별"(기록), "행성"(카테고리), "탐사선", "싣기", "복사하기"를 쓴다. "보내기", "전송", "발사"는 쓰지 않는다.
시간 기준모든 날짜와 "N일 전"은 기록을 넣은 시각 기준.
키보드W·A·S·D 이동, Space 상승, Shift 하강, 드래그 시점, E 착륙, Esc 패널·서랍 닫기. 입력창에 포커스가 있을 때는 비행 키를 받지 않는다.
확인 단계삭제·합치기는 화면 안에서 확인받는다. 브라우저 확인창을 쓰지 않는다.
문구오류는 무엇이 안 됐는지와 다음 행동을 한 줄로. 사과 문구를 붙이지 않는다.
개인정보기록은 내 PC에만 있다. 밖으로 나가는 건 탐사선에서 사용자가 복사한 것과 링크 제목을 가져오는 요청뿐이다.
